# LPU Assist – AI-Powered University Admission Chatbot

LPU Assist is a domain-specific AI chatbot designed to provide intelligent, real-time admission guidance for university applicants. The system acts as a virtual admission counsellor using Generative AI to deliver personalised, context-aware, and conversational support.

## Problem Statement
Students often face difficulties in:
- Understanding admission procedures
- Checking eligibility criteria
- Getting accurate fee and scholarship details
- Receiving instant counselling support

LPU Assist solves these challenges through an AI-powered conversational system.

## Features
- AI Chat Assistant using Retell AI API
- Real-time admission guidance
- Course recommendation system
- Campus visit booking support
- Context-aware conversation handling
- Guided admission workflow
- Responsive chat interface
- Session-based interaction support

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express.js
- API Communication: Axios
- AI Integration: Retell AI API
- Styling: CSS / Tailwind (if used)
